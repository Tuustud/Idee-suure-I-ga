# Idee-suure-I-ga
Rühmaliikmete nimed: Roland Parts, Rauno Lopp ja Aleksander Budašov

Idee-suure-I-ga projekti eesmärk on luua veebileht, mis võtab kasutajalt aja sisendi (nt kus kasutaja praegu on ja palju tal aega on) ning annab talle vastavalt oma sisendile mingi huvitava tegevuse mida kasutaja võib proovida.

Meie ideedegeneraatori algallikas: https://www.youtube.com/watch?v=rnZorHI_Y28
